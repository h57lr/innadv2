# Enad Al-Shneikat Portfolio Website

## Project Purpose
A premium personal portfolio website for Enad Al-Shneikat, positioning him as a digital marketing, marketing technology, performance marketing, tracking, automation, BI, and analytics expert.

## Main Instruction
Before making changes, read:
- docs/master-prompt.md
- docs/project-brief.md
- docs/brand-guidelines.md
- docs/todo.md
- references/inspiration-links.md
- references/competitor-notes.md

## Development Rules
- Do not build randomly.
- Work phase by phase.
- Do not create only the homepage.
- Use reusable components.
- Validate all routes, buttons, mobile layout, and build errors before claiming completion.
- Do not invent fake metrics, fake results, or confidential claims.
- Update docs/changelog.md after major changes.

## Preferred Stack
Next.js, React, TypeScript, Tailwind CSS, App Router, and reusable component architecture.

## Development Commands
npm install
npm run dev
npm run build
